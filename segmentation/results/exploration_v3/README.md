# 精度提升尝试（2026-10-23）：没有方案过关，run_02 保持不变

目标：在 ESP32-S3 速度预算内（板上单核每张不超过 60 ms）提高水体分割精度。全部实验只用 80 张标定图，
没有加载任何 TEST 图像或标注；挑选规则在看到结果前写好（[selection_rule.md](selection_rule.md)，含一次带时间戳的修改）。
指标是"漏检 5% 时的水体误检"（标定集，按原图分辨率），越小越好。

## 先诊断 run_02 错在哪（[diagnose_run02.py](diagnose_run02.py)）

| | 漏检 | 误检 |
|---|---:|---:|
| run_02 int8（部署阈值） | 4.63% | 14.31% |
| 80×60 输出完全正确时的上限 | 0.41% | 1.64% |
| 160×120 输出完全正确时的上限 | 0.13% | 1.26% |

- 输出分辨率不是瓶颈；只有 29% 的错误落在标注边缘一个输出格以内，其余是整块区域判错。
- 误检集中在画面下方：下三分之一的水 24% 被判成非水体，上三分之一 11%。

## 结果

| 方案 | 种子 | 浮点 | int8（ESP-PPQ，设备一致的输入码） |
|---|---:|---:|---:|
| lite（run_02 结构，基准） | 3 | 12.16%（13.14 / 12.44 / 10.89） | **12.50%**（13.55 / 12.79 / 11.16） |
| lite + 全局上下文门控 | 3 | 13.26% | — |
| lite + Dice 损失 | 3 | 12.14% | — |
| lite + 权重滑动平均 | 3 | 11.94% | — |
| lite，以 mnv3s_nose 为老师蒸馏 | 3 | 12.50% | — |
| 预训练 MobileNetV3-small 编码器（无 SE）mnv3s_nose | 3 | **9.08%**（8.00 / 9.44 / 9.79） | 26%～89%（11 种量化设置） |
| 同上，带 SE | 1 | 8.23% | 不可部署（ESP-PPQ 报 SE 层在 S3 上溢出） |
| 同结构，不用预训练权重 | 1 | 11.35% | — |
| mnv3s_relu（Hardswish 换 ReLU、去掉门控） | 1 | 9.63% | 78%（默认）→ 16.6%（层间均衡）→ **11.4%**（均衡 + LSQ 2000 步） |

lite 种子 20261022 的 int8 结果与锁定的 run_02 完全相同（13.55%），说明探索流程复现了部署模型。
量化试验的全部设置与结果在 [quant_trials.json](quant_trials.json)。

## 结论

- 按规则，新方案要比 lite 平均好 max(1 个百分点, 2 倍种子标准差) 才算数：浮点约 2.3 个百分点，int8 约 2.4 个百分点。
  能部署的最好方案 mnv3s_relu 量化后只好 1.1 个百分点，而且只有一个种子，不过关。run_02 继续作为部署模型。
- 浮点下真正有效的是 ImageNet 预训练（约 3 个百分点），在 lite 上做小改动或蒸馏都没有用。
- 预训练模型的优势在 S3 上量化后大部分消失：ESP-PPQ 对 S3 的卷积权重按整层用一个 2 的幂次缩放（只有 P4 按通道），
  BatchNorm 合并后各通道的权重大小差异很大，小通道被量化成 0（首层单层误差 119%）。
  ReLU + 层间均衡 + LSQ 能挽回大半，但仍剩约 1.8 个百分点的量化损失。
- 混合精度（前几层 int16）在这里无法评估：首层改成 int16 后输入也要 16 位，而板上预处理只产生 int8 输入。
- 预训练模型在 5% 漏检上限下的潜水员召回（81%～82%）低于 lite（86%），误检少的代价落在潜水员上，避障时要注意。

## 接下来值得做的

1. 用自己的 OV2640 实拍水池画面（几十到几百张，按拍摄批次划分）微调和验证：SUIM 是海洋照片，和泳池差别最大，这一步最可能带来真实场景的提升。
2. 在机器人上做时间滤波（如连续 2/3 帧都判为非水体才算障碍），5 张/秒、低速运动下几乎不增加计算；需要视频才能评估。
3. 对 mnv3s_relu 做量化感知训练（QAT），有望把 int8 拉近浮点的 9.6%；预计收益 1～2 个百分点，需要再上板测速。
4. 若硬件可换 ESP32-P4：按通道量化，预训练模型可以直接部署。

## 文件

- `explore_v3.py`：多种子训练与标定评估；`models_v3.py`：MobileNetV3-small 编码器的候选结构。
- `export_candidate.py`：候选模型导出 int8 并按标定集选阈值，生成可嵌入固件的模型目录（未锁定）。
- `quant_trials.py`：ESP-PPQ 量化设置试验（层间均衡、LSQ、分块重建、混合精度等）。
- `round1/`、`round2/`、`round3/`：各轮 `results.jsonl`；保留了 mnv3s_nose 三个种子和 mnv3s_relu 的权重，供以后做 QAT 或当老师用。
- 这些脚本原本在会话临时目录运行；`explore_v3.py` 里老师权重的路径相对于脚本所在目录。
