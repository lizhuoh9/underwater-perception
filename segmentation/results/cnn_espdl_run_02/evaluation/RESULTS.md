# 轻量 CNN（lite）锁定评估

网络结构由只用标定集的探索选出；模型、两个阈值与 ESP-DL 导出都在加载 TEST 前锁定，TEST 只评估这一次。int8 结果使用与 ESP32-S3 相同的输入量化码运行 ESP-PPQ 量化图。run_01 与森林、UDCP 的数字来自它们已记录的逐图结果。

run_02：22.3 MMAC/帧（run_01 为 69.7），39,569 个参数，16 个卷积层，输出 80×60。

- 部署阈值码 +3（预先登记：标定漏检上限 5%；标定漏检 4.63%，误检 14.31%）。固件头文件与自检帧用这个阈值。
- 对照阈值码 +10（与森林阈值 71、run_01 锁定阈值相同的上限 7.88%；标定漏检 7.86%，误检 9.39%）。

run_01 的 +5 阈值是看过 TEST 后选的，它的 TEST 数字不是独立检验；这里列出只为同上限对照。

## 限制

- 同一批 SUIM 照片的复用比较，不是 OV2640 实拍；水色、曝光、白平衡与防水窗差异需要实拍数据验证。
- 结构选择用了与阈值相同的 80 张标定图，标定数字略偏乐观；TEST 未参与任何选择。
- int8 结果是 ESP-PPQ 对 ESP32-S3 的仿真；板上一致性与速度由 water_seg_demo 实测确认。
- 输出为水体/非水体分割，不是碰撞距离。
